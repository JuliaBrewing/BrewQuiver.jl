Provenance and export

Shares and attribution

shares(res, q, product) gives the share of each lot (ingredient or water) used for a product:

shares(res, q, :bottles)
Dict{Symbol, Float64} with 7 entries:
  :sparge_water  => 1.0
  :strike_water  => 1.0
  :pale          => 1.0
  :crystal       => 1.0
  :priming_sugar => 1.0
  :goldings      => 1.0
  :yeast         => 1.0

In a single batch everything goes to the one product, so all the shares are 1; in a parti-gyle they split (see A parti-gyle).

attribution(res, q, product) gives the share of every node: the fraction of its contents that goes into making the product, following the liquor, with what is left behind (spent grain, trub, yeast cake) allocated to the products it serves.

attribution(res, q, :bottles)
Dict{Symbol, Float64} with 17 entries:
  :grain_bed     => 1.0
  :mash          => 1.0
  :priming_sugar => 1.0
  :beer          => 1.0
  :goldings      => 1.0
  :sparge_water  => 1.0
  :strike_water  => 1.0
  :pale          => 1.0
  :chilled       => 1.0
  :wort          => 1.0
  :bottling      => 1.0
  :bottles       => 1.0
  :crystal       => 1.0
  :fermentor     => 1.0
  :rested        => 1.0
  :yeast         => 1.0
  :kettle        => 1.0

In a parti-gyle, the shares of each lot among the beers add up to what was used of it, which is how a quiver turns into one recipe per beer.

BeerJSON recipes

BeerJSON recipes are linear, so a quiver is exported as one recipe per product, holding the shares of its lots: recipe(res, q, product), recipes(res, q) for all the products, and writejson(path, res, q) for a BeerJSON document.

r = recipe(res, q, :bottles; name = "Bitter", author = "BrewQuiver")
(r.name, quantity(r.batch_size), quantity(r.original_gravity))
("Bitter", 22.04202369904633 L, 1.0536099513756245 sg)
path = writejson(tempname() * ".json", res, q; author = "BrewQuiver")
length(readjson(BeerJSONParser, path).beerjson.recipes)
1

The recipe has the mash steps, the boil (with its hop stand), the fermentation steps, the additions with their timing, the water and the efficiency of the brew (brewhouse_efficiency). A recipe exported from a quiver and imported back (with the equipment of its kettle) brews to the same wort and beer.
